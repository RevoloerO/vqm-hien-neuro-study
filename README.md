# Neuro Study Guide

Nursing study guide built from 9 neuro course files (Cranial Nerves, IICP, Stroke, Meningitis/Encephalitis, Seizures, Headaches, Parkinson's, MS/MG, Delirium/Dementia/Alzheimer's).

- **v2: Patient Care Review** (`/`): source-only, organized by the nursing process (Assess → Plan → Implement → Evaluate), slide citations, Professor's Questions, Bedside Check practice questions, mind map.
- **Practice test** (`/test/`): 50 random questions from an 84-question bank built only from the slides; new order on every load; instant rationale with slide number; results by topic and nursing step.
- **v1: Topic Review** (`/v1/`): topic-by-topic review with comparison tables, medication list, mind map. Includes some added material marked ➕.

- **Document versions** (`/doc/v2.html`, `/doc/v1.html`): printable pages of both guides with Print / Save as PDF.

Live: https://revoloero.github.io/vqm-hien-neuro-study/
